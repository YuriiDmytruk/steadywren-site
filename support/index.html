Support

Questions, bugs or feature requests for any Steadywren product: write to support@steadywren.com, or open an issue on the product's page in Apify Store.

Please include:

  • the product name;
  • the run ID or a link to the failed run, if there is one;
  • what you expected and what you got (the input you used, a few example rows).

Every message gets a real answer from the person who built the product. Broken results caused by a change on the source website are fixed first.
